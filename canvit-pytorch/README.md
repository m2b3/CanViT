# canvit-pytorch

PyTorch implementation of CanViT, the Canvas Vision Transformer, from
[CanViT: Toward Active-Vision Foundation Models](https://arxiv.org/abs/2603.22570).

Documentation, checkpoints, examples and the other CanViT packages:
<https://github.com/m2b3/CanViT>.

```bash
uv add "canvit-pytorch @ git+https://github.com/m2b3/CanViT.git#subdirectory=canvit-pytorch/core"
```

This package is also on PyPI (`uv add canvit-pytorch`), updated less often
than the git version.
