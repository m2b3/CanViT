# canvit-pytorch

PyTorch implementation of CanViT, the Canvas Vision Transformer, from
[CanViT: Toward Active-Vision Foundation Models](https://arxiv.org/abs/2603.22570) (NeurIPS 2026).

```bash
pip install canvit-pytorch
```

Checkpoints: <https://huggingface.co/canvit>. Documentation and examples: <https://github.com/m2b3/CanViT>.
